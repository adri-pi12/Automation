# Lab 02 - Currency Exchange Rate

## Description

This project contains a Python script that interacts with a local Currency Exchange Rate API.

The script receives two currencies and a date as command-line arguments, requests the exchange rate from the API, and saves the received result in JSON format.

The supported data period is from 2025-01-01 to 2025-09-15.

## Requirements

- Python 3
- pip
- Currency Exchange Rate service running on http://localhost:8080
